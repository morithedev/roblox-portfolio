01 / Combat

Simple combat system

Close-range M1 and M2 combos, blocks, sprint attacks and knockback. Damage, targets and cooldowns are handled by the server.

  • Server-side checks
  • Training dummies
  • Attack states

02 / Inventory

Inventory and item prompts

Pick up tagged items, equip them from three slots and drop them back into the world. The server checks the item, distance, ownership and available space.

  • Three item slots
  • Server validation
  • World pickups

03 / Physics

Drag, weight and throw

Pick up, carry and throw physics objects. Each object can use its own weight, throw force and interaction range, with server checks before an item moves.

  • Object weight
  • Throw force
  • Interaction range

04 / Character systems

R6 and R15 ragdoll

Toggle ragdoll for both character rigs, keep the camera with the character and leave death ragdolls in the world. Server state and request limits support multiplayer play.

  • R6 and R15
  • Camera follow
  • Request limits

05 / Framework

Tink game framework

A typed, Knit-style framework for Roblox services and controllers. It uses Spark modules for remotes and module discovery, with staged startup and Promise-based hooks.

  • Remote signals
  • Rate limiting
  • Staged startup

Payment and delivery

Scope, payment, and ownership.

Most commissions are paid per task after delivery. A 50/50 split also works: half before I start and half on delivery. I accept Robux, Mastercard transfers, gift cards and crypto. I don't take revenue share or payment after a game ships.

Ownership

Once a task is paid for, that code is yours. You can modify and ship it anywhere. I don't keep a copy.

Refunds

You can stop at any time. With per-task work, you only pay for what has been delivered. With 50/50, the upfront half is refundable until I start.

Availability

I'm available 6-12 hours a day (UTC+3). I reply within hours on Discord.

Robux payments

The project amount is based on the current DevEx rate. You cover Roblox's 30% marketplace fee. Payment can be sent through a game pass or group funds. See current DevEx terms.
